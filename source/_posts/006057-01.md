Vâng. Nghĩ đến khoảng thời gian còn lại trước vòng bán kết,

{% enddialogue %}

{% dialogue chiharu %}
Gần đây Akari và Yuu cũng hăng hái lắm……
Bọn mình còn bị Hiiragi-san lườm vì cứ tập quá sức nữa đấy.
{% enddialogue %}

{% dialogue haruka %}
Hì hì, vậy à.
Trước đây tớ cũng từng bị mắng như thế rồi.
{% enddialogue %}

{% dialogue chiharu %}
……Dạo gần đây, phía Kiritani-san và mọi người thế nào rồi?
{% enddialogue %}

{% dialogue haruka %}
Chắc cũng giống bên cậu thôi.
Ai cũng rất quyết tâm.
{% enddialogue %}

{% dialogue haruka %}
Đã đi đến tận đây rồi thì bọn tớ cũng muốn giành chức vô địch……
Nên ngày nào cả nhóm cũng đang ra sức luyện tập.
{% enddialogue %}

{% dialogue chiharu %}
Vậy sao……
{% enddialogue %}

{% dialogue chiharu %}
Nghe thế, mình cũng thấy yên tâm hơn.
{% enddialogue %}

{% dialogue haruka %}
Hả?
{% enddialogue %}

{% dialogue chiharu %}
Vì đối thủ của MORE MORE JUMP! là Cheerful*Days mà.
{% enddialogue %}

{% dialogue chiharu %}
Họ đã vượt qua vòng loại với vị trí dẫn đầu,
lại còn nổi tiếng với những màn trình diễn live xuất sắc nữa.
{% enddialogue %}

{% dialogue chiharu %}
Mình nghĩ phải đối đầu với một nhóm như vậy
hẳn sẽ khiến các cậu chịu rất nhiều áp lực……
{% enddialogue %}

{% dialogue haruka %}
……Ừ, đúng vậy.
Ngay cả trên mạng xã hội, các fan cũng tỏ ra lo lắng cho bọn tớ.
{% enddialogue %}

{% dialogue chiharu %}
……Vâng. Mình cũng đã thấy những ý kiến như thế.
{% enddialogue %}

{% dialogue chiharu %}
Nhưng Kiritani-san lúc này trông rất bình tĩnh——
Cứ như cậu chẳng còn bị những lời bàn tán hay đánh giá xung quanh chi phối,
mà chỉ tập trung vào những gì mình cần làm vậy.
{% enddialogue %}

{% dialogue haruka %}
……Nếu vậy thì có lẽ cũng nhờ Tsubaki-san đấy.
{% enddialogue %}

{% dialogue chiharu %}
Ơ……? Nhờ mình sao?
{% enddialogue %}

{% dialogue haruka %}
Ừ. Khi vừa biết nội dung thi đấu của vòng bán kết……
thật ra tớ vẫn còn rất nhiều điều băn khoăn.
{% enddialogue %}

{% dialogue haruka %}
Dù đã cùng mọi người trao đổi ý kiến,
tìm cách đối đầu với Cheerful*Days——
{% enddialogue %}

{% dialogue haruka %}
Bọn tớ vẫn chưa tìm ra con đường nào khiến mình tin rằng có thể chiến thắng.
{% enddialogue %}

{% dialogue haruka %}
Nhưng…… cuộc trò chuyện với Tsubaki-san đã cho tớ một gợi ý.
{% enddialogue %}

{% dialogue chiharu %}
Gợi ý……?
{% enddialogue %}

{% dialogue haruka %}
Hôm đó, cậu đã kể cho tớ nghe chuyện hồi còn ở một nhóm khác, đúng không?
{% enddialogue %}

{% dialogue haruka %}
Cậu nói rằng quyết định ấy là điều cần thiết để thực sự biến ước mơ thành hiện thực.
Rằng có những thứ chỉ có thể đạt được khi ta dám quyết tâm bứt phá.
{% enddialogue %}

{% dialogue haruka %}
——Nhờ những lời ấy,
bọn tớ mới tìm thấy con đường mình cần đi.
{% enddialogue %}

{% dialogue haruka %}
Vậy nên, cảm ơn cậu.
{% enddialogue %}

{% dialogue chiharu %}
Mình chỉ kể lại chuyện ngày xưa thôi mà……
{% enddialogue %}

{% dialogue chiharu %}
Nhưng nếu điều đó có thể giúp ích dù chỉ một chút cho Kiritani-san và mọi người, thì mình rất vui.
{% enddialogue %}

{% dialogue chiharu %}
Đến ngày biểu diễn, cả hai nhóm hãy cố gắng để không phải hối tiếc nhé.
{% enddialogue %}

{% dialogue haruka %}
Ừ. Cùng cố gắng hết sức nhé.
{% enddialogue %}

{% dialogue haruka %}
Vậy, tớ đi trước đây.
{% enddialogue %}

{% dialogue chiharu %}
Vâng, cậu vất vả rồi!
{% enddialogue %}
