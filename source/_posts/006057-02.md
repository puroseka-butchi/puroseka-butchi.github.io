{% dialogue haruka %}
——Có chỗ nào trong màn trình diễn khiến cậu thấy chưa ổn à?
{% enddialogue %}

{% dialogue minori %}
Ừ! Tớ muốn nhờ hai cậu xem thử,
nếu thấy chỗ nào cần sửa thì chỉ cho tớ với.
{% enddialogue %}

{% dialogue minori %}
Trước khi Shizuku-chan kết thúc kỳ nghỉ và quay lại,
tớ muốn hoàn thiện thật tốt phần biểu diễn của mình!
{% enddialogue %}

{% dialogue airi %}
Quyết tâm ghê nhỉ.
{% enddialogue %}

{% dialogue haruka %}
Để xem nào. Theo những gì tớ quan sát được thì……
{% enddialogue %}

{% dialogue haruka %}
Có vài động tác của cậu vẫn chưa thật vững,
và tớ cũng hơi để ý đến cách cậu sử dụng ánh mắt.
{% enddialogue %}

{% dialogue minori %}
Ánh mắt sao?
{% enddialogue %}

{% dialogue haruka %}
Ừ. Ở đoạn điệp khúc có chỗ Shizuku bước lên phía trước, đúng không?
Đến đoạn đó, cậu thử đưa mắt nhìn theo Shizuku xem.
{% enddialogue %}

{% dialogue haruka %}
Như vậy, khán giả sẽ dễ cảm nhận được hơn
rằng cậu đang đuổi theo Shizuku từ phía sau.
{% enddialogue %}

{% dialogue minori %}
Ra là vậy……
{% enddialogue %}

{% dialogue airi %}
Ngoài ra, cậu nên chú ý đến dư âm của từng động tác nữa.
{% enddialogue %}

{% dialogue airi %}
Như sau khi vung tay thế này,
có một đoạn cậu phải giữ nguyên tư thế trong vài giây, đúng không?
{% enddialogue %}

{% dialogue airi %}
Thay vì vừa dừng lại đã vội chuyển sang động tác tiếp theo,
cậu hãy tưởng tượng mình đang để khán giả nhìn thật rõ khoảnh khắc dừng ấy.
{% enddialogue %}

{% dialogue minori %}
Giữ tư thế thật chắc để làm nổi bật dư âm của động tác……
{% enddialogue %}

{% dialogue minori %}
Cảm ơn hai cậu nhiều nhé!
Tớ thử lại một lần nữa được không?
{% enddialogue %}

{% dialogue haruka %}
Ừ. Vậy ba chúng ta cùng tập từ đoạn trước điệp khúc nhé.
{% enddialogue %}

{% dialogue haruka %}
——Năm, sáu, bảy, tám!
{% enddialogue %}

{% dialogue minori %}
Hộc…… hộc…… Thế nào rồi?
{% enddialogue %}

{% dialogue airi %}
Khá lắm, Minori!
Động tác của cậu vừa rồi sắc nét ra trò đấy!
{% enddialogue %}

{% dialogue haruka %}
Ừ.
Tớ thấy cậu cũng đã chú ý đến hướng nhìn của mình rồi.
{% enddialogue %}

{% dialogue minori %}
Ehehe, đều nhờ hai cậu chỉ cho tớ đấy!
{% enddialogue %}

{% dialogue minori %}
Được rồi, tớ phải tập thêm
để có thể thực hiện những động tác đó thật tự nhiên mới được!
{% enddialogue %}

{% dialogue haruka %}
À…… khoan đã, Minori.
Chúng ta tập lâu rồi, cũng đến lúc nghỉ một chút thôi.
{% enddialogue %}

{% dialogue haruka %}
Khi đang tập trung thì khó nhận ra lắm,
nhưng chắc chắn cơ thể cậu đã mệt rồi đấy.
{% enddialogue %}

{% dialogue minori %}
À, cũng đúng nhỉ……!
{% enddialogue %}

{% dialogue airi %}
Không cần vội đâu. Cứ tiến bộ thế này thì
đến khi Shizuku trở lại, cậu sẽ hoàn thiện được kha khá rồi.
{% enddialogue %}

{% dialogue haruka thought %}
(……Không biết giờ này Shizuku đang làm gì nhỉ.)
{% enddialogue %}

{% dialogue haruka thought %}
(Tìm cách vượt qua nỗi sợ……)
{% enddialogue %}

{% dialogue haruka thought %}
(Tớ biết đó không phải chuyện dễ dàng đối với Shizuku.)
{% enddialogue %}

{% dialogue haruka thought %}
(Nhưng——)
{% enddialogue %}

{% dialogue airi %}
……Haruka?
{% enddialogue %}

{% dialogue haruka %}
Hả……?
{% enddialogue %}

{% dialogue airi %}
……Có phải cậu đang nghĩ đến Shizuku không?
{% enddialogue %}

{% dialogue haruka %}
……Ừ.
{% enddialogue %}

{% dialogue haruka %}
Giá như tớ suy nghĩ thấu đáo hơn về hoàn cảnh của Shizuku……
và những điều cậu ấy đang mang trong lòng.
{% enddialogue %}

{% dialogue haruka %}
Cuối cùng, tớ lại để Shizuku phải gánh vác tất cả——
{% enddialogue %}

{% dialogue airi %}
Đó đâu phải chuyện để cậu tự nhận trách nhiệm.
Cả nhóm đã cùng nhau đưa ra quyết định ấy mà, đúng không?
{% enddialogue %}

{% dialogue airi %}
Với thực lực của bọn mình hiện giờ,
tớ vẫn nghĩ đó là cách duy nhất để đối đầu với Cheerful*Days.
{% enddialogue %}

{% dialogue minori %}
Airi-chan……
{% enddialogue %}

{% dialogue airi %}
Hơn nữa, cậu cũng biết mà.
{% enddialogue %}

{% dialogue airi %}
Shizuku có hơi lơ ngơ thật đấy, nhưng đến lúc quyết định thì cậu ấy chẳng bao giờ chùn bước đâu.
{% enddialogue %}

{% dialogue airi %}
——Chính vì thế mà cậu mới giao vị trí center cho Shizuku, đúng không?
{% enddialogue %}

{% dialogue haruka %}
……Ừ, đúng là vậy.
{% enddialogue %}

{% dialogue haruka %}
Tớ không biết Shizuku sẽ tìm được câu trả lời như thế nào, nhưng——
{% enddialogue %}

{% dialogue haruka %}
Tớ tin rằng Shizuku nhất định sẽ vượt qua được.
{% enddialogue %}

{% dialogue minori %}
Ừ……! Tớ cũng tin như thế!
{% enddialogue %}

{% dialogue haruka %}
Vậy sau khi nghỉ xong, chúng ta hãy hoàn thiện thật tốt đoạn vừa rồi nhé.
{% enddialogue %}

{% dialogue haruka %}
Để khi Shizuku quay lại, cậu ấy phải bất ngờ mới được.
{% enddialogue %}
