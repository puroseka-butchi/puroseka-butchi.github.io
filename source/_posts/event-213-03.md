{% enddialogue %}

{% dialogue arisawa %}

{% dialogue arisawa %}

{% enddialogue %}

{% dialogue arisawa %}

các bạn phải không ngừng mài giũa ánh sáng của mình.
{% enddialogue %}

{% dialogue arisawa %}

mình nên trở thành người như thế nào.
{% enddialogue %}

{% dialogue arisawa %}

Cũng sẽ có lúc một người khác được chọn

{% enddialogue %}

{% dialogue haruka %}
