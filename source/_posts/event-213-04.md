{% dialogue haruka %}
Vậy thì, bắt đầu luôn nhé...
Trước tiên, hãy quyết định về ca khúc mới đã.
{% enddialogue %}

{% dialogue minori %}
Bọn mình sẽ được một nhạc sĩ nổi tiếng sáng tác riêng cho đúng không!
Không biết nên chọn một bài như thế nào nhỉ?
{% enddialogue %}

{% dialogue airi %}
Ừm——nhưng tớ nghĩ bọn mình phải suy nghĩ thật kỹ
rồi mới đưa ra yêu cầu.
{% enddialogue %}

{% dialogue minori %}
Hả?
{% enddialogue %}

{% dialogue shizuku %}
...Người dẫn chương trình đã nói rồi nhỉ.
『Các bạn muốn “thể hiện” bản thân như thế nào——khả năng là vô hạn』.
{% enddialogue %}

{% dialogue haruka %}
Ừm. Hơn nữa, lần này thắng thua
chỉ được quyết định bằng phiếu bầu của ban giám khảo.
{% enddialogue %}

{% dialogue haruka %}
Nếu xem đây là một vòng thi mà độ nổi tiếng
hay mức độ ủng hộ từ fan không liên quan,
và chỉ thuần túy đánh giá chất lượng màn trình diễn——
{% enddialogue %}

{% dialogue haruka %}
thì tớ nghĩ cách bọn mình tự định hướng và xây dựng hình ảnh cho nhóm
cũng sẽ được xem là một yếu tố quan trọng.
{% enddialogue %}

{% dialogue minori %}
Ra là vậy...
{% enddialogue %}

{% dialogue minori %}
Bọn mình phải suy nghĩ thật kỹ xem
muốn tạo nên một sân khấu như thế nào,
rồi từ đó mới tính đến chuyện ca khúc nhỉ.
{% enddialogue %}

{% dialogue airi %}
Chính là thế.
{% enddialogue %}

{% dialogue airi %}
Với lại... dù gì đi nữa,
đối thủ tiếp theo của bọn mình cũng là Cheerful*Days.
{% enddialogue %}

{% dialogue airi %}
Phải bước vào trận đấu với quyết tâm
làm tất cả những gì có thể.
{% enddialogue %}

{% dialogue shizuku %}
Ở vòng loại,
bọn mình đã có rất nhiều lần hợp tác với Arisa-chan và mọi người...
{% enddialogue %}

{% dialogue shizuku %}
Nhưng lần này,
hai bên sẽ thật sự đối đầu trực diện với nhau nhỉ.
{% enddialogue %}

{% dialogue minori %}
...Theo những dự đoán trên mạng xã hội,
có vẻ mọi người đều nghĩ Cheerful*Days sẽ thắng.
{% enddialogue %}

{% dialogue airi %}
Cũng đương nhiên thôi.
Ngay cả ở Trade Live của vòng loại,
thực lực biểu diễn của họ đã áp đảo rồi.
{% enddialogue %}

{% dialogue airi %}
Khi đó là live chung nên còn ổn...
nhưng lần này là đối đầu một chọi một.
{% enddialogue %}

{% dialogue airi %}
Dù rất không cam lòng, nhưng nếu nhìn một cách khách quan...
bọn mình rõ ràng đang ở thế bất lợi hơn rất nhiều.
{% enddialogue %}

{% dialogue haruka %}
............
{% enddialogue %}

{% dialogue haruka thought %}
(...Quả nhiên mọi người đều đang cảm thấy bất an)
{% enddialogue %}

{% dialogue haruka thought %}
(『Bọn mình sẽ ổn thôi』, 『Rồi sẽ có cách』——)
{% enddialogue %}

{% dialogue haruka thought %}
(Có lẽ mình nên động viên mọi người
bằng những lời lạc quan như thế...)
{% enddialogue %}

{% dialogue haruka %}
——Ừm.
{% enddialogue %}

{% dialogue haruka %}
Nếu cứ như hiện tại,
tớ nghĩ bọn mình không có cơ hội thắng.
{% enddialogue %}

{% dialogue haruka %}
...Nếu nhìn một cách khách quan,
Cheerful*Days sẽ là bên thắng ở vòng tiếp theo.
Tớ rất hiểu vì sao mọi người xung quanh lại nghĩ như vậy.
{% enddialogue %}

{% dialogue haruka %}
Nhưng không có nghĩa
bọn mình hoàn toàn không có cơ hội.
{% enddialogue %}

{% dialogue minori %}
Hả...?
{% enddialogue %}

{% dialogue haruka %}
Arisawa-san đã nói rồi nhỉ.
Để dù ở giữa bất kỳ thay đổi nào,
bọn mình vẫn có thể tỏa sáng theo cách của chính mình——
{% enddialogue %}

{% dialogue haruka %}
thì phải luôn suy nghĩ xem mình cần làm gì
và không ngừng nỗ lực.
{% enddialogue %}

{% dialogue shizuku %}
Ừm...
{% enddialogue %}

{% dialogue haruka %}
Mục tiêu của bọn mình
là mang hy vọng đến cho thật nhiều người.
Nhưng để làm được điều đó,
bọn mình phải trở nên mạnh hơn.
{% enddialogue %}

{% dialogue haruka %}
Phải dốc hết sức suy nghĩ để chiến thắng,
rồi không ngừng nỗ lực...
Tớ nghĩ có những thứ
chỉ khi vượt qua chính bản thân mình của trước đây
thì mới có thể nắm lấy được.
{% enddialogue %}

{% dialogue haruka %}
Nếu bọn mình có thể tìm ra
một ánh sáng mạnh mẽ chỉ thuộc về riêng mình——
thì nhất định sẽ không thua Cheerful*Days đâu.
{% enddialogue %}

{% dialogue minori %}
Haruka-chan...
{% enddialogue %}

{% dialogue airi %}
Gì đây, hiếm khi thấy cậu nhiệt huyết thế đấy?
{% enddialogue %}

{% dialogue haruka %}
Vậy sao?
Tớ nghĩ mình lúc nào cũng thế mà.
{% enddialogue %}

{% dialogue shizuku %}
Fufu...
{% enddialogue %}

{% dialogue minori %}
——Nhờ Haruka-chan,
tớ bắt đầu cảm thấy bọn mình thật sự có thể làm được rồi!
{% enddialogue %}

{% dialogue shizuku %}
Đúng vậy...!
Mọi người cùng cố gắng nhé.
{% enddialogue %}

{% dialogue haruka %}
Vậy thì, cả nhóm cùng thử đưa ra ý tưởng nhé.
{% enddialogue %}

{% dialogue shizuku %}
Ừm. Trước hết là
bọn mình muốn tạo nên một sân khấu như thế nào nhỉ.
{% enddialogue %}

{% dialogue airi %}
Xét việc bọn mình chỉ được trình diễn một ca khúc,
tớ nghĩ dù thế nào cũng cần một thứ gì đó đủ sức gây ấn tượng.
{% enddialogue %}

{% dialogue minori %}
Gây ấn tượng à...
Có lẽ nên là một ca khúc mạnh mẽ,
có thể khiến không khí bùng lên ngay từ đầu chăng?
{% enddialogue %}

{% dialogue haruka thought %}
(...Tình thế bất lợi vẫn chẳng thay đổi chút nào)
{% enddialogue %}

{% dialogue haruka thought %}
(Dù vậy——mình nhất định sẽ tìm ra)
{% enddialogue %}

{% dialogue haruka thought %}
(Con đường để bọn mình có thể
tỏa sáng hơn cả Cheerful*Days——!)
{% enddialogue %}
