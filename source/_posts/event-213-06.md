em cũng đề xuất video của người này.
{% enddialogue %}

{% dialogue chiharu %}
Không chỉ nói về tập cơ,
người này còn giới thiệu cả kiến thức dinh dưỡng
để xây dựng thể trạng nữa.
{% enddialogue %}

{% dialogue haruka %}
Ồ... nghe có vẻ học được nhiều thứ đấy.

{% dialogue chiharu %}
Vâng!
{% enddialogue %}

{% dialogue haruka thought %}

{% dialogue chiharu %}

{% dialogue haruka %}
Fufu, ra là vậy.
{% enddialogue %}

{% dialogue chiharu %}

{% enddialogue %}

{% dialogue haruka %}

{% enddialogue %}

{% dialogue haruka %}
Tùy nguyên liệu và phương pháp sản xuất,
khả năng hấp thu cũng khác nhau.

{% enddialogue %}

{% dialogue chiharu %}
Quả nhiên là vậy!
{% enddialogue %}

{% dialogue haruka thought %}

{% dialogue haruka thought %}
(Hơn nữa——)

{% dialogue haruka %}

{% enddialogue %}

{% dialogue chiharu %}
Không đâu, em mới là người phải cảm ơn.

{% dialogue chiharu %}
Những phương pháp tập luyện chị vừa chỉ,

{% dialogue haruka %}
Có ích cho em là tốt rồi.
{% enddialogue %}

Vì thế em muốn rèn cơ thể thật tốt.
{% enddialogue %}

{% dialogue chiharu %}

{% dialogue chiharu %}
