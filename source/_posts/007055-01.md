{% dialogue airi %}
——MEIKO, KAITO-san, hai người vất vả rồi!
{% enddialogue %}

{% dialogue meiko-mmj %}
Ô, Airi-chan! Cậu tới rồi à.
{% enddialogue %}

{% dialogue kaito-mmj %}
Hôm nay cậu đến một mình nhỉ.
Có chuyện gì sao?
{% enddialogue %}

{% dialogue airi %}
Ừ, tớ đến vì có chuyện muốn nói với MEIKO.
Hay là hai người đang bàn chuyện gì đó?
{% enddialogue %}

{% dialogue kaito-mmj %}
Bọn tớ đang bàn về buổi live tiếp theo.
Nhưng cũng vừa xong đúng lúc, nên không sao đâu.
{% enddialogue %}

{% dialogue meiko-mmj %}
Vậy chuyện cậu muốn nói là gì thế?
{% enddialogue %}

{% dialogue airi %}
Thật ra, tớ muốn rủ MEIKO tham gia một việc vui lắm.
{% enddialogue %}

{% dialogue meiko-mmj %}
Lời mời à?
{% enddialogue %}

{% dialogue meiko-mmj %}
A, chẳng lẽ là……!
Buổi gặp mặt với những người cậu đã gặp ở SEKAI đó sao?
{% enddialogue %}

{% dialogue airi %}
Ơ, cậu nghe ai kể rồi à?
{% enddialogue %}

{% dialogue meiko-mmj %}
Fufu, Miku và mọi người bảo là họ cũng sẽ tham gia ấy mà.
{% enddialogue %}

{% dialogue airi %}
Ra là vậy.
{% enddialogue %}

{% dialogue airi %}
Này, tớ đã kể là bọn tớ gặp MEIKO
ở SEKAI có một cái cây lớn rồi đúng không?
{% enddialogue %}

{% dialogue airi %}
Vậy nên bọn tớ mới bàn là sẽ mời MEIKO
ở SEKAI của mỗi người đến buổi gặp mặt đó.
{% enddialogue %}

{% dialogue kaito-mmj %}
Ồ, thế thì chắc sẽ náo nhiệt lắm đây!
{% enddialogue %}

{% dialogue airi %}
Vậy cậu thấy sao?
Đến đó chắc chắn sẽ vui lắm đấy!
{% enddialogue %}

{% dialogue meiko-mmj %}
Ừ, tất nhiên là tớ sẽ tham gia rồi!
{% enddialogue %}

{% dialogue meiko-mmj %}
Được trò chuyện với những “tớ” ở các SEKAI khác,
nghe thú vị quá mà♪
{% enddialogue %}

{% dialogue airi %}
Cảm ơn nhé!
Tớ biết MEIKO sẽ đồng ý mà.
{% enddialogue %}

{% dialogue kaito-mmj %}
À, nhắc mới nhớ——
{% enddialogue %}

{% dialogue kaito-mmj %}
MEIKO-san ở SEKAI có cái cây mà Airi-chan và mọi người đã gặp,
là người như thế nào vậy?
{% enddialogue %}

{% dialogue meiko-mmj %}
Tớ cũng tò mò chuyện đó lắm!
{% enddialogue %}

{% dialogue airi %}
Để xem nào. Bọn tớ cũng không có dịp nói chuyện lâu, nhưng……
{% enddialogue %}

{% dialogue airi %}
Có cảm giác như một người chị rất điềm đạm ấy.
Chị ấy cực kỳ dịu dàng, còn luôn để ý quan tâm đến bọn tớ nữa.
{% enddialogue %}

{% dialogue airi %}
Điểm chững chạc, đáng tin thì
có lẽ cũng khá giống MEIKO đấy.
Mà nói kiểu này thì khó biết tớ đang nói MEIKO nào thật.
{% enddialogue %}

{% dialogue meiko-mmj %}
Fufu. Có điểm giống nhau làm tớ vui lắm.
Biết đâu cả chuyện có thể nhảy cũng giống nhau thì sao nhỉ?
{% enddialogue %}

{% dialogue meiko-mmj %}
Nếu cùng mặc một bộ trang phục lên live,
chắc sẽ trông như sinh đôi và khiến sân khấu náo nhiệt lắm đấy!
{% enddialogue %}

{% dialogue airi %}
Đúng thật, chắc chắn sẽ là một buổi live thu hút mọi ánh nhìn!
{% enddialogue %}

{% dialogue meiko-mmj %}
Đúng không?
Một ngày nào đó tớ cũng muốn gặp MEIKO ấy thử xem.
{% enddialogue %}

{% dialogue kaito-mmj %}
Ừ nhỉ. Tớ cũng tò mò lắm.
{% enddialogue %}

{% dialogue meiko-mmj %}
Ừ! Nhưng trước đó, lúc này——
{% enddialogue %}

{% dialogue meiko-mmj %}
Tớ đang rất mong được gặp những người sở hữu SEKAI khác.
Tất cả đều là người quen của Airi-chan đúng không?
{% enddialogue %}

{% dialogue airi %}
Đúng vậy đó.
Tớ thật sự bất ngờ lắm!
{% enddialogue %}

{% dialogue airi %}
Không ngờ ngay gần mình lại có nhiều người sở hữu SEKAI đến thế……
Đúng là người ta nói thế giới nhỏ thật chẳng sai.
{% enddialogue %}

{% dialogue kaito-mmj %}
Hơn nữa còn không phải chỉ một hai người, mà là rất nhiều nữa chứ.
{% enddialogue %}

{% dialogue meiko-mmj %}
Lúc nghe kể, tớ cũng bất ngờ lắm đấy!
{% enddialogue %}

{% dialogue airi %}
……Nhưng nghĩ kỹ lại thì,
có khi chuyện đó cũng chẳng lạ đến vậy đâu.
{% enddialogue %}

{% dialogue kaito-mmj %}
Ý cậu là sao?
{% enddialogue %}

{% dialogue airi %}
Ena, Akito-kun, cả Kusanagi-san nữa——
{% enddialogue %}

{% dialogue airi %}
Ai cũng luôn mang một ý chí mạnh mẽ,
thẳng tiến theo đuổi ước mơ của mình.
{% enddialogue %}

{% dialogue airi %}
Nghĩ vậy thì tớ thấy họ có một SEKAI
của riêng mình cũng chẳng có gì lạ.
{% enddialogue %}

{% dialogue kaito-mmj %}
Ồ, đến mức Airi-chan nói như vậy,
hẳn họ phải là những người tuyệt lắm nhỉ……!
{% enddialogue %}

{% dialogue meiko-mmj %}
Fufu, tớ càng lúc càng mong được gặp mọi người rồi đấy!
{% enddialogue %}

{% dialogue airi %}
Ừ, cứ mong chờ đi!
{% enddialogue %}

{% dialogue airi %}
Đặc biệt là Ena, cậu ấy là người bạn thân mà tớ rất tự hào.
Tớ nhất định muốn giới thiệu cậu ấy với mọi người!
{% enddialogue %}

{% dialogue meiko-mmj %}
Thật sao?
{% enddialogue %}

{% dialogue airi %}
Ừ! Ena vẽ những bức tranh tuyệt lắm luôn ấy!
{% enddialogue %}

{% dialogue airi %}
Dù cũng từng có lúc cậu ấy khựng lại một chút……
nhưng lần nào cũng tự vực mình dậy rồi cố hết sức bước tiếp!
{% enddialogue %}

{% dialogue kaito-mmj %}
……Fufu, đúng là một người bạn rất quan trọng với cậu nhỉ.
{% enddialogue %}

{% dialogue meiko-mmj %}
——Ừ.
{% enddialogue %}

{% dialogue meiko-mmj %}
Tớ càng lúc càng muốn làm thân với mọi người hơn rồi đấy, Airi-chan!
{% enddialogue %}

{% dialogue airi %}
Thật à? Vậy thì tốt quá!
{% enddialogue %}

{% dialogue kaito-mmj %}
Hai người cứ tận hưởng buổi gặp mặt nhé.
Tớ cũng mong được nghe hai người kể xem đã rôm rả về những chuyện gì!
{% enddialogue %}

{% dialogue airi %}
Ừ, tất nhiên rồi!
{% enddialogue %}

{% dialogue airi %}
Cơ hội thế này hiếm lắm,
tớ sẽ cố để buổi gặp mặt thật suôn sẻ!
{% enddialogue %}
