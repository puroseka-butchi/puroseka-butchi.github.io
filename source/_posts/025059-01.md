{% dialogue meiko-ln %}

{% enddialogue %}

{% dialogue meiko-ln %}

Nhưng chiến dịch này hay thật đấy ạ!
{% enddialogue %}

Ừm, để chị nghĩ xem nào...
{% enddialogue %}

{% enddialogue %}

{% dialogue meiko-ln %}
Nhưng SEKAI này cũng chẳng có nội quy gì nghiêm ngặt,
nên thật ra cũng không có chuyện gì cần phải nhắc nhở gay gắt cả.
{% enddialogue %}

{% dialogue meiko-ln %}
Ở trường của hai đứa thì có đủ loại nội quy, đúng không?

{% enddialogue %}

{% dialogue saki %}
Nếu ăn diện nổi bật quá thì vẫn bị nhắc nhở đấy ạ.
{% enddialogue %}

{% dialogue meiko-ln %}
Chị nhớ việc kiểm tra mấy chuyện như thế cũng thuộc nhiệm vụ của ban kỷ luật nhỉ?

{% dialogue meiko-ln %}
Chị cũng muốn thử làm xem sao, nhưng ở đây lại chẳng có nội quy gì...
Có kiểm tra thì chắc chị cũng chỉ biết khen mọi người thôi.
{% enddialogue %}

{% dialogue honami %}
Khen... ạ?
{% enddialogue %}

{% dialogue meiko-ln %}

hay "Bộ đồ đó hợp với cậu lắm!" ấy.
{% enddialogue %}

{% dialogue saki %}
A...! Nhắc mới nhớ, anh trai em cũng là thành viên ban kỷ luật ở trường Kamiyama——
{% enddialogue %}

{% dialogue saki %}
Trước khi em ra khỏi nhà,
anh ấy cũng hay khen kiểu tóc của em lắm đó!
{% enddialogue %}

{% dialogue honami %}

{% enddialogue %}

{% dialogue meiko-ln %}

{% enddialogue %}

{% dialogue honami %}
Việc ra dáng thành viên ban kỷ luật...
{% enddialogue %}

{% dialogue saki %}

{% enddialogue %}

{% dialogue meiko-ln %}
Vậy chị thử chấn chỉnh mọi thứ một phen xem sao nhé?

{% dialogue honami %}
Ơ...?
{% enddialogue %}

{% dialogue saki %}
Mọi thứ luôn ạ?
{% enddialogue %}

{% dialogue meiko-ln %}

Mọi người lập tức đặt nhạc cụ xuống, chuyển sang giờ uống trà!"
{% enddialogue %}

{% dialogue meiko-ln %}
...Kiểu thế đấy?

{% dialogue meiko-ln %}

{% enddialogue %}

{% dialogue saki %}
Vâng! Em sẽ mong chờ lắm đấy ạ!
{% enddialogue %}

{% dialogue meiko-ln %}
Cảm ơn hai đứa đã kể cho chị bao nhiêu chuyện nhé.
{% enddialogue %}

{% dialogue meiko-ln %}

{% enddialogue %}

{% dialogue meiko-ln %}
