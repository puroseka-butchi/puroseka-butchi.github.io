Ừm, đúng hết rồi đấy.

Oa, Icchan hiểu cách làm rồi kìa!

{% enddialogue %}

Bài kiểm tra ngắn lần trước tớ làm khá chật vật.
{% enddialogue %}

{% dialogue honami %}
Dạo này bọn mình bận mấy buổi diễn, 
nên tớ cũng muốn tranh thủ ôn lại một chút.
{% enddialogue %}

{% dialogue honami %}
Với cả, tớ thấy bài học trên lớp gần đây càng lúc càng khó hơn...
{% enddialogue %}

{% dialogue saki %}
Phải phải!
Công thức mới nè, ngữ pháp mới nữa... 
nhiều đến mức đầu tớ sắp nổ tung rồi～!
{% enddialogue %}

{% dialogue ichika %}
Mà nếu bị điểm kém thì còn phải làm thêm bài tập nữa nhỉ.
{% enddialogue %}

{% dialogue shiho %}
Ừ. Thế thì lại mất thời gian tập luyện. 
Tớ không muốn vậy chút nào.
{% enddialogue %}

{% dialogue honami %}
Vậy nên mấy bài kiểm tra ngắn cũng phải cố gắng hết sức nhé.
{% enddialogue %}

{% dialogue honami %}
Hiếm khi cả nhóm cùng học thế này, 
chỗ nào chưa hiểu thì mình cùng chỉ cho nhau.
{% enddialogue %}

{% dialogue honami %}
Tớ biết gì thì sẽ chỉ hết, 
nên có thắc mắc cứ hỏi tớ bất cứ lúc nào nhé.
{% enddialogue %}

{% dialogue saki %}
Vâng～! Mong cô giáo Hona-chan chỉ bảo ạ!
{% enddialogue %}

{% dialogue ichika %}
Vở ghi của Honami lúc nào cũng đẹp thật đấy.
{% enddialogue %}

{% dialogue shiho %}
Các ý chính được tóm tắt gọn gàng, lại rõ ràng. 
Này có khi dễ hiểu hơn cả sách tham khảo nữa.
{% enddialogue %}

{% dialogue saki %}
Ơ...? Phần giải thích trong khung này, 
bọn mình đã học trên lớp rồi ư?
{% enddialogue %}

{% dialogue honami %}
À... phần đó tớ tự tìm hiểu rồi ghi thêm vào đấy.
{% enddialogue %}

{% dialogue honami %}
Tớ nghĩ những từ tiếng Anh có nghĩa gần giống nhau thì cũng nên tìm hiểu cả sự khác biệt về sắc thái nữa.
{% enddialogue %}

{% dialogue saki %}
Ra là vậy～...!
{% enddialogue %}

{% dialogue shiho %}
Khi dịch cổ văn sang tiếng Nhật hiện đại, 
cậu thường chú ý điều gì?
{% enddialogue %}

{% dialogue honami %}
Ừm... chắc là phải chú ý cách dùng trợ động từ 
để không dịch sai chăng?
{% enddialogue %}

{% dialogue honami %}
À, tớ có một quyển sách giải thích bằng manga và tranh minh họa, đọc thú vị lắm. Lần sau tớ mang đến cho cậu nhé.
{% enddialogue %}

{% dialogue shiho %}
Thật à? Cảm ơn cậu.
{% enddialogue %}

{% dialogue ichika %}
Honami, bọn tớ cũng muốn hỏi chút, được không?
{% enddialogue %}

{% dialogue shiho %}
...Có cả hàng người chờ rồi kìa, cô giáo.
{% enddialogue %}

{% dialogue honami %}
Ahaha...
{% enddialogue %}

<p class="translation-scene-title">Vài giờ sau</p>

{% dialogue saki %}
Xong rồi～! Sao tớ lại thấy mệt hơn cả lúc tập nhạc thế này...
{% enddialogue %}

{% dialogue honami %}
Mọi người vất vả rồi.
{% enddialogue %}

{% dialogue ichika %}
Cảm ơn Honami đã chỉ cho bọn tớ nhiều thứ nhé.
Nhờ cậu mà bài kiểm tra ngắn lần tới chắc sẽ ổn thôi.
{% enddialogue %}

{% dialogue shiho %}
Ừ. Đúng là tranh thủ ôn lại thật kỹ từ bây giờ thì tốt hơn.
{% enddialogue %}

{% dialogue shiho %}
Nhưng... Honami có cần học nhóm như bọn tớ đâu nhỉ?
{% enddialogue %}

{% dialogue honami %}
Ơ?
{% enddialogue %}

{% dialogue ichika %}
Đúng thật. Nãy giờ Honami cứ phải giảng bài cho bọn tớ suốt mà.
{% enddialogue %}

{% dialogue honami %}
Không đâu. Được học cùng mọi người, 
tớ cũng có thêm động lực mà.
{% enddialogue %}

{% dialogue honami %}
Hơn nữa, giảng bài cho người khác cũng là một cách để mình ôn lại kiến thức nữa.
{% enddialogue %}

{% dialogue shiho %}
Vậy thì được——
{% enddialogue %}

<p class="translation-scene-title"><i>Ọc ọc... tiếng bụng Saki réo lên...</i></p>

{% dialogue honami %}
Ơ, tiếng vừa rồi là...
{% enddialogue %}

{% dialogue saki %}
Ehehe... học hành chăm chỉ quá nên bụng tớ réo lên rồi!
{% enddialogue %}

{% dialogue honami %}
Cũng đến giờ ăn nhẹ rồi nhỉ. 
Tớ có làm ít bánh mang đến để cả nhóm cùng ăn đấy.
{% enddialogue %}

{% dialogue saki %}
Yay! Từ nãy tớ đã ngửi thấy mùi gì ngọt ngọt từ Hona-chan rồi, nên cứ mong mãi thôi～♪
{% enddialogue %}

{% dialogue honami %}
Fufu. Tớ làm nhiều lắm, nên mọi người cứ ăn thoải mái nhé.

{% dialogue ichika %}

{% enddialogue %}

{% dialogue saki %}
Tớ đi pha trà nhé!

{% enddialogue %}

{% dialogue saki %}

Ehehe, madeleine, madeleine～♪
